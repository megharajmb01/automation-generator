Processing of LSQ BRD section wise and storing the section data in a chroma RAG. Retierval of a chunk related to a section.


Front End Application


This is a react application

Prerequisite:
Node js : node v22.13.1 (npm v10.9.2)
GitHub Link : https://github.com/thiru-metaz/pdf-testcase-generator


Steps to Start :

1) git clone https://github.com/thiru-metaz/pdf-testcase-generator.git
2) cd pdf-testcase-generator
3) nvm use 22
4) npm i 
5) npm start 

this should start the application and run the application on localhost:3000

-----------------------------------------------------------------------


Back End Application

Prerequiste:

Python 3.10.12

Github link: https://github.com/vinutha-metaz/lsq-test-case


Steps to start:

1) git clone https://github.com/vinutha-metaz/lsq-test-case
2) cd lsq-test-case
3) pip install -r requirements.txt
4) python3 fastapi_server.py


this should start the back end API services.
this will run on the localhost:8000
